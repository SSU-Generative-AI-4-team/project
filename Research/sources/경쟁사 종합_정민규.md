## 1. 요약

1. **"글 쓰고 버리기"만으로는 차별화가 안 된다.** '감정쓰레기통'이라는 이름의 앱이 이미 4개 넘게 있고(감쓰, 요단강, thingapps, Studio Handot), Scream into the Void나 Pixel Thoughts처럼 쓴 글을 사라지게 하는 서비스도 이미 있다.
2. **"배출 + 의미 있는 반복 의식 + 누적 보상"을 모두 갖춘 서비스는 없다.** 배출형(감쓰, 아무것도아니야)에는 다시 올 이유가 없다. 의식형(석가머니, 불교마음, 목탁치기)은 감정과 이어지지 않는다. 보상형(Finch, MOODA)에는 배출이 없다. 이 세 가지를 **하나의 루프로 잇는 것**이 우리 자리다.
3. **PRD가 먼저 보완해야 할 부분은 네 가지다.** ① 원문 보관 정책과 프라이버시 약속, ② 보상 기준(배출 횟수만 세면 부정 감정을 늘리는 쪽으로 유도될 수 있다), ③ 종교색 조절, ④ 서비스 이름.
4. MVP는 **작게** 만든다. 기능이 많아서 버그와 데이터 손실이 생긴 사례(아무것도아니야)가 있고, 이 시장은 아직 초기 단계다(조재영 종합).

### 팀원 간 관점 차이 (정리 필요)

- **조재영·정연화·홍석민**은 "배출과 의미 부여를 같이 가진 곳이 없다 → 빈자리가 있다"고 본다.
- **김서영**은 "소각 연출 자체는 차별점이 아니다. 단순 삭제보다 종료감이 높아지는지부터 검증해야 한다"고 본다. 불교 문구와 염주의 효과도 근거가 부족하다고 평가했다.
- → 두 관점은 충돌하지 않는다. **빈자리는 있지만, 그 빈자리를 사용자가 원하는지는 아직 검증되지 않았다.** 그래서 MVP를 검증용으로 설계해야 한다.

## 3. PRD 대비 갭 분석

| PRD 항목 | 현재 PRD | 경쟁사에서 확인된 점 | 갭 |
| --- | --- | --- | --- |
| 5.1 감정 배출 | 텍스트 + 선택 태그 | Daylio·하루콩은 아이콘만으로도 입력 가능. Vent는 음성 입력 | 텍스트를 쓰기 버거운 날을 위한 대안이 없음 |
| 5.2 소각 연출 | 분쇄기, 화로, 물 등 여러 옵션 | 감쓰는 이미 던지기와 변기 두 가지를 제공. 강하게 표출한다고 풀린다는 근거는 없음(메타분석) | 옵션 수로는 차별화가 안 됨. 연출의 톤(잔잔함 vs 파괴)이 정의되지 않음 |
| 5.2 위로 문구 | 무작위 불교 문구 | 불교마음과 석가머니 모두 '하루 한 줄 말씀'이 있음. 종교색은 비신자에게 진입장벽 | 종교색의 강도와 비종교 문구를 섞는 전략이 없음 |
| 5.3 염주 적립 | 배출 1회 = 1알, 108알이면 완성 | 석가머니도 108을 쓰는 구조. Finch는 작은 **돌봄 행동**에 보상을 줌 | 보상 기준이 '부정 감정 배출 횟수'라서 목표가 왜곡될 수 있음 |
| 6. 플로우 5단계 | 적립 뒤 부수 이벤트 (코멘트) | 석가머니의 부처 꾸미기, Finch의 펫 성장·모험, MOODA의 스티커 | 부수 이벤트를 무엇으로 할지 정해지지 않음 |
| 6. 플로우 6단계 | 염주 돌리기로 안정 | 불교마음과 석가머니에 이미 구현됨. Pixel Thoughts는 60초로 끝나는 시간을 정해 둠 | 돌리기를 몇 번, 몇 초 할지(종료 조건)가 없음 |
| 7. 차별화 | 기록 대신 배출, 스트릭 없음 | Finch는 스트릭 복구·일시정지로 부담을 줄임 | '안 와도 죄책감 없음'을 구현할 방법이 구체적이지 않음 |
| 8. 리텐션 | 퇴근 시간 알림, 진행률, 문구 확장 | 감쓰의 매일 비우기 알림과 감정 카드 공유, Vent Now의 재방문 리마인드, 석가머니의 걸음 수 보상 | 알림 외에 다시 올 계기가 부족함 |
| 9. 수익 | 연출, 스킨, 리포트 유료화 | 감쓰는 유료 앱, 아무것도아니야는 광고, Finch·MOODA는 꾸미기 구독, Pixel은 후원 | 핵심 배출 기능을 무료로 둘지 명시되지 않음 |
| 10. 리스크 | 정신건강 안전장치 검토 | 아무것도아니야는 PHQ-9로 임상 쪽으로 감. 톤이 무거워짐 | 가벼운 톤을 유지하면서 위기에 대응하는 방식이 없음 |
| (없음) | 데이터 보관 정책 | 감쓰는 "개발자도 못 봄"과 생체 잠금, 요단강은 로컬 저장. Pixel은 시각적으로는 사라져도 서버에 저장 | **PRD에 보관 정책이 아예 없음** |
| (없음) | 서비스 이름 | '감정쓰레기통' 앱이 4개 이상 | 스토어 검색 경쟁과 혼동 위험 |
| (없음) | 온보딩 | Scream·Pixel은 가입 없이 바로 입력 | 가입이 필요한지 정의되지 않음 |

## 6. PRD 반영 제안 요약 (v0.2 후보)

1. **신규 절 '데이터 정책'**: 원문은 저장하지 않는다(또는 기기에만 둔다). 서버에는 태그, 시각, 염주 수만 저장한다.
2. **5.2 처리 방식**: 옵션 나열을 '감정 태그 → 추천 의식' 매핑으로 바꾸고, 잔잔한 연출 1~2종으로 시작한다.
3. **5.3 염주 적립 기준**: '배출 1회'를 '배출 + 마무리 의식 완료 1회'로 바꾼다.
4. **6. 플로우 5·6단계**: 부수 이벤트는 염주 꾸미기로 하고, 돌리기에 종료 조건을 명시한다.
5. **7·8절**: 스트릭 없음을 '돌아오면 반기기'로 구체화한다. 하루 한 줄 말씀과 안부 리마인드는 TEST로 둔다.
6. **9절**: "핵심 배출은 영구 무료"를 원칙으로 명시한다.
7. **10절**: 위기 키워드 안내를 MVP에 포함한다.
8. **서비스 이름**: 네이밍 후보 회의가 필요하다.
