## 읽는 법

모든 루프를 같은 네 칸으로 나눴다.

```mermaid
flowchart LR
  T["계기<br/>왜 여는가"] --> A["행동<br/>무엇을 하는가"] --> R["보상<br/>끝나고 무엇을 받는가"] --> K["남는 것<br/>다시 올 이유"]
  K -.->|"다시 오기"| T
  classDef ok fill:#e8f5e9,stroke:#2e7d32,color:#1b1b1b
  class T,A,R,K ok
```

| 색 | 뜻 |
| --- | --- |
| 초록 | 이 칸은 작동한다 |
| 빨강 | **루프가 여기서 끊긴다** |
| 노랑 | 작동은 하지만 우리 정체성(원문을 남기지 않음, 프라이빗, 가벼운 톤)과 부딪친다 |
| `--x` 화살표 | 다시 오기로 이어지지 않는다 |

## 결론

| 끊기는 자리 | 서비스 | 한 줄 |
| --- | --- | --- |
| **남는 것이 없음** | 감쓰, Scream, 요단강 | 버리면 끝이라 다시 열 이유도 같이 사라진다 |
| **행동이 감정과 무관** | 석가머니, 불교마음 | 의식은 있지만 오늘의 감정을 쓰거나 버리는 단계가 없다 |
| **남는 것이 원문·기록** | Pixel, 아무것도아니야, MOODA, Daylio | 루프는 닫히지만 기록을 남겨서 닫는다 |
| **스트릭·기록 의존** | Finch | 가장 잘 닫힌 루프지만 스트릭과 기록에 기댄다 |

**네 칸이 모두 초록인 서비스는 없다.** 우리 루프(맨 끝)는 이 네 칸을 원문 없이 채우는 조합이다 `[추정]`.

## 1. 배출형 — 남는 것이 없음

### 1-1. 감쓰 (감정쓰레기통: 마음 비우기)

```mermaid
flowchart LR
  T["계기<br/>짜증·민망한 감정<br/>매일 비우기 알림"] --> A["행동<br/>적기 →<br/>종이공 던지기<br/>또는 물 내리기"] --> R["보상<br/>감정청소부 위로"] --> K["남는 것<br/>없음 (즉시 삭제)"]
  K --x|"다시 열 이유 없음"| T
  classDef ok fill:#e8f5e9,stroke:#2e7d32,color:#1b1b1b
  classDef broken fill:#ffebee,stroke:#c62828,color:#1b1b1b
  class T,A,R ok
  class K broken
```

- 배출 경험은 조사한 곳 중 가장 강하다. "개발자도 못 본다"는 약속, 생체 잠금 [조재영/01]
- 글이 사라지면서 앱을 다시 열 이유도 사라진다 [조재영/01]. 알림과 감정 카드 공유가 있다는 조사도 있지만 출처가 없다 [정민규]

```mermaid

  K --x|"'다시 배출' 링크뿐"| T
```

- 소멸 동작의 원형. 스트릭·수집·통계·알림 미관찰 [김서영] S1

## 2. 의식형 — 행동이 감정과 무관

### 2-1. 석가머니 (Seokgamoney: Buddha Luck)

```mermaid
flowchart LR
  T["계기<br/>Angry? Tap.<br/>Anxious?<br/>Spin."] --> A["행동<br/>목탁 108번<br/>/ 염주 굴리기<br/>(쓰기·버리기 없음)"] --> R["보상<br/>액땜 한 바퀴<br/>하루 한 줄 말씀"] --> K["남는 것<br/>운 재화 →<br/>부처 꾸미기<br/>걸음 수 보상"]
  K -.->|"꾸미기·재화"| T
  classDef ok fill:#e8f5e9,stroke:#2e7d32,color:#1b1b1b
  classDef broken fill:#ffebee,stroke:#c62828,color:#1b1b1b
  class T,R,K ok
  class A broken
```

- **가장 가까운 의식형 경쟁자.** 감정 상태와 행동은 연결했지만, 감정을 적거나 버리는 과정이 없다 [정민규] [홍석민]
- 루프 자체는 재화와 꾸미기로 닫혀 있다
- ⚠️ 원본 조사에 URL이 없다. 위 내용은 `[미확인]`이다

### 2-2. 불교마음

```mermaid
flowchart LR
  T["계기<br/>오늘의 운세·명언"] --> A["행동<br/>염주 돌리기<br/>목탁 소리<br/>연등 달기"] --> R["보상<br/>명언 · 운세"] --> K["남는 것<br/>없음<br/>(적립·통계·레벨<br/>없음)"]
  K --x|"매일 콘텐츠만"| T
  classDef ok fill:#e8f5e9,stroke:#2e7d32,color:#1b1b1b
  classDef broken fill:#ffebee,stroke:#c62828,color:#1b1b1b
  classDef warn fill:#fff8e1,stroke:#f9a825,color:#1b1b1b

  class T,A,K broken
```

- 계기가 감정이 아니라 운세·명언이다. 염주 UX 선례이고, "연등 귀엽다" 반응이 있다 [조재영/03]
- 종교색이 강해 젊은 비신자에게는 진입장벽이다 [조재영/03]

- 배출 다음 단계까지 설계해서 루프는 닫힌다. 다만 계기와 남는 것이 임상적이라 톤이 무겁다 [조재영/02]
- 기능이 많아 버그·데이터 손실 리뷰가 반복된다 [조재영/02]

- 스티커 꾸미기가 사용자 요청으로 추가돼 크리에이터 스티커까지 확장된 사례다 [조재영/04]
- 배출이 아니라 **전시**다. 공감·댓글은 우리의 프라이빗 배출과 부딪친다

## 5. 우리 루프 (비교용)

```mermaid
flowchart LR
  T["계기<br/>감정 그 자체<br/>(매일 오게<br/>만들지 않음)"] --> A["행동<br/>쓰기 → 태우기<br/>→ 한 알 굴리기"] --> R["보상<br/>한 줄 위로<br/>아무도 읽지 않았어요"] --> K["남는 것<br/>물든 알<br/>(원문 없음,<br/>기기 저장)"]
  K -.->|"다음에 속상할 때"| T
  classDef ok fill:#e8f5e9,stroke:#2e7d32,color:#1b1b1b
  class T,A,R,K ok
```

| 칸 | 가져온 곳 | 버린 것 |
| --- | --- | --- |
| 계기 | 감쓰·Scream의 "감정이 계기" | 불교마음의 운세·명언 계기 |
| 행동 | 감쓰의 버리는 감각 + 석가머니의 굴리기 | 요단강의 대화형 입력, 아무것도아니야의 CBT 일기 |
| 보상 | Scream의 안도 문구, Pixel의 정해진 끝 | AI 피드백, 공감·댓글 |
| 남는 것 | Finch·석가머니의 "행동에 따라 쌓이는 흔적" | 원문 저장(Pixel), 기록·통계(Daylio), 스트릭(Finch) |
