## 결론

1. **"체류 시간을 늘린다"를 그대로 목표로 삼으면 우리 루프와 부딪친다.** 우리 루프의 핵심은 "끝이 정해진 짧은 의식"이다 [루프]. Pixel Thoughts도 60초로 끝을 정해 종료감을 만든다 [김서영]. 그래서 목표를 **"루프가 끝난 뒤, 사용자가 원해서 더 머무는 시간"** 으로 좁혔다. 루프 안의 시간을 늘리지 않는다.
2. **경쟁사의 체류 장치는 다섯 종류다.** 반복 동작, 콘텐츠 소비, 꾸미기, 소셜, 기록 되돌아보기(1장). 이 가운데 원문을 남기지 않고 쓸 수 있는 건 **반복 동작, 꾸미기, 짧은 콘텐츠** 세 가지다.
3. **제안은 하나를 먼저 하고, 나머지는 뒤로 미룬다.**
   - **첫 번째: 한 바퀴 호흡.** 홈의 염주 18알을 숨 한 번에 한 알씩 넘기는 약 2~3분짜리 모드다. 이미 만든 염주 화면을 다시 쓰므로 추가 비용이 가장 적다. 석가머니의 한 바퀴, 아무것도아니야 호흡법의 긍정 리뷰, Pixel의 정해진 끝이 근거다.
   - 나머지 세 개(풍경 소리, 소원 연등, 염주 공방)는 첫 사용자가 생긴 뒤에 검토한다(2장).

## 0. 먼저 짚을 점 — 왜 목표를 좁혔나

| 부딪치는 지점 | 내용 | 근거 |
| --- | --- | --- |
| 루프의 끝 | ⑤ 한 알 굴리기는 5~10초로 끝나야 종료감이 생긴다. 여기서 시간을 늘리면 "버리고 후련하다"가 약해진다 | [루프] 2-1, Pixel 60초 [김서영] |
| 필요할 때 쓰는 도구 | 매일 오래 머무는 앱이 아니다. "낮은 일간 방문율만으로 실패를 판단하면 안 된다" | [김서영] 8장 |
| 부정 감정 붙잡기 | 쓰기 화면에 오래 머물게 하면 부정 감정을 곱씹는 시간이 늘어난다 | [대체안] 3.1 원칙 5 "비운 것에 초점" |
| 첫 버전 크기 | AGENTS 0-3 "첫 버전이 작다" | 워크스페이스 기준 |

**그래서 좋은 체류를 이렇게 정의한다** `[추정]`
- 루프(①~⑥)가 **끝난 뒤** ⑥ 홈에서 시작된다
- 사용자가 **스스로** 고른다. 기본값으로 이어지지 않는다
- **끝이 정해져 있다.** 무한히 이어지는 피드나 자동 재생을 쓰지 않는다
- 원문과 부정 감정으로 **되돌아가지 않는다**

## 2. 기능 제안

### 2-1. 요약

| 순위 | 기능 | 한 줄 | 단계 |
| --- | --- | --- | --- |
| 1 | **한 바퀴 호흡** | 숨 한 번에 염주 한 알, 18알을 넘기면 끝 | **TEST — 첫 버전 후보** |
| 2 | 풍경 소리 | 염주를 돌리는 동안 잔잔한 배경 소리 | LATER |
| 3 | 소원 연등 | 비운 자리에 바라는 것 한 줄을 연등에 띄워 보냄 | LATER, TEST 필요 |
| 4 | 염주 공방 | 해금한 색·재질·장식으로 염주를 꾸미는 화면 | LATER (해금 생긴 뒤) |

### 2-2. 한 바퀴 호흡 (1순위)

| 항목 | 내용 |
| --- | --- |
| 한 문장 | 숨 한 번에 염주 한 알을 넘기고, 18알을 다 넘기면 끝난다 |
| 루프 위치 | ⑥ 홈에서 "한 바퀴 돌리기" 버튼. ⑤ 직후 한 줄로 권하되("조금 더 머물다 갈까요?"), 기본으로 이어지지 않는다 |
| 흐름 | 염주가 화면 가운데 → 들숨(알이 천천히 밝아짐) → 날숨에 사용자가 한 알 넘김 → 18번 → "한 바퀴 돌았어요" + 한 줄 문구 → 홈 |
| 시간 | 숨 한 번 약 6~10초 × 18 ≈ **2~3분** `[추정]`. 중간에 나가도 불이익 없음 |
| 끝 | 18알 = 한 바퀴. 석가머니의 "한 바퀴"와 같은 단위 [정민규], 대체안의 18알 염주를 그대로 쓴다 [대체안] 3.3 |
| 남는 데이터 | 없음 (적립하지 않는다. 적립은 ⑤ 한 알 굴리기로만) |
| 비용 | 새 화면 없이 ⑥ 염주 컴포넌트에 호흡 속도 안내와 완료 문구만 추가 |
| 근거 | 아무것도아니야 호흡법 긍정 리뷰 [조재영/02], Pixel 정해진 끝 + Connected Breath [김서영], Finch 호흡 행동 [김서영], 석가머니·불교마음 굴리기 UX [정민규] [조재영/03] |
| 왜 적립이 없나 | 체류에 보상을 붙이면 "오래 머물수록 보상"이 되어 다시 목표가 비틀린다. 적립 기준은 [루프]의 "태우기 + 한 알 굴리기" 하나로 유지한다 |

**검증** (김서영 TEST "잔잔한 소멸 vs 짧은 호흡"과 같이 돌린다)

| 질문 | 방법 |
| --- | --- |
| 태운 뒤 한 바퀴를 스스로 고르는가 | ⑤ 이후 "한 바퀴 돌리기"를 누르는 비율 |
| 끝까지 도는가 | 18알 완주율 (낮아도 실패 아님, 몇 알에서 나가는지 봄) |
| 더 가벼워지는가 | 태운 직후 vs 한 바퀴 후 "조금 가벼워졌나요?" 5점 비교 |

### 2-3. 나머지 (LATER)

| 기능 | 내용 | 끝 | 근거 | 뒤로 미룬 이유 |
| --- | --- | --- | --- | --- |
| 풍경 소리 | 한 바퀴 호흡이나 홈에서 돌릴 때 빗소리·풍경 소리 1~2종 | 한 바퀴가 끝나면 같이 꺼짐 | Finch 사운드스케이프 [김서영], 목탁치기·불교마음 목탁 소리 [정민규] [조재영/03], 대체안의 소리 해금 [대체안] 3.6 | 소리 에셋과 저작권 확인이 필요. 한 바퀴 호흡의 이용률을 본 뒤 |
| 소원 연등 | ③ 태운 재가 연등이 되어 떠오르고, 원하면 바라는 것 한 줄을 적어 함께 띄움. **이 글도 저장하지 않는다** | 연등이 화면 밖으로 나가면 끝 | 불교마음 연등 "귀엽다" [조재영/03], 요단강 종잇배 [정연화] | 부정 → 긍정 전환이 위로인지 부담인지 모른다. 쓰기를 한 번 더 요구하므로 루프가 길어진다. TEST 필요 |
| 염주 공방 | 해금한 색·재질·매듭으로 염주를 바꿔 보는 화면 | 저장하면 끝 | 석가머니 부처 꾸미기 [정민규], MOODA 스티커 [조재영/04], Finch 꾸미기 [김서영] | 꾸밀 것이 1개뿐인 첫 버전에서는 머물 이유가 없음 [루프] 4장. 해금이 3개 이상 생긴 뒤 |

### 2-4. 넣지 않을 것

| 장치 | 출처 | 이유 |
| --- | --- | --- |
| 자동 두드리기 / 무한 돌리기 | 목탁치기 [정민규] | 끝이 없고 의미 없이 시간만 쓴다 |
| 감정 통계 들여다보기 | Daylio, 아무것도아니야 | 원문·감정 기록이 남는다 |
| 공감·댓글 | MOODA, thingapps | 프라이빗 배출과 충돌 |
| AI 대화 | 아무것도아니야, 요단강 | "아무도 읽지 않았어요"와 충돌. 배출 효과를 분리해 검증하기 어려움 `[추정]` |
| 대량 명상 콘텐츠 | 마보 | 제작 비용. 첫 버전 범위를 넘음 |
| 체류 시간 비례 보상 | — | 오래 머물수록 보상하면 목표가 비틀린다 |

## 3. 체류를 어떻게 잴까

**전체 세션 시간은 목표 지표로 쓰지 않는다.** 쓰기 화면에서 오래 머문 것(부정 감정을 오래 붙잡은 것)도 체류로 잡히기 때문이다 `[추정]`.

| 지표 | 정의 |
| --- | --- |
| 자발 체류 | ⑥ 홈 도달 **이후** 머문 시간 |
| 한 바퀴 선택률 | ⑤ 이후 한 바퀴 호흡을 고른 비율 |
| 한 바퀴 완주율 | 시작한 한 바퀴 중 18알을 다 넘긴 비율 |

첫 버전은 서버가 없으므로 [루프] 5장처럼 소규모 사용자 테스트에서 관찰로 잰다.
