## 결론

**108개를 모아야 완성되는 염주를 버리고, "첫날부터 가진 기본 염주를 조금씩 물들이고 꾸미는" 구조로 바꾼다.**

- 소각 → **한 알 굴리기** → 굴린 알이 물듦. 이 한 흐름이 적립 1회다. 하루 최대 3회까지 적립된다.
- 보상은 짧은 주기로 온다: 1·3·6·10·15·21·28회, 그 뒤로는 5회마다. 3번에 1번은 **고르는 뽑기**다.
- 18알이 다 물들면 "한 바퀴"를 완성하고, 다음 바퀴는 색이 한 겹 깊어진다. **6바퀴 = 108**은 조용한 서브 목표다.
- 원문은 남기지 않는다. 날짜, 시간대, 태그, 횟수만으로 **월 1회 비움 카드**를 만든다.
- 쉬어도 잃는 것이 없다. 진행도는 멈출 뿐 줄지 않는다.

### "스트릭보다 기록·통계"라는 발견을 어떻게 반영했나

- 경쟁사가 가장 많이 쓰는 재방문 장치는 쌓인 기록을 되돌아보게 하는 것이다 [종합 3장].
- 우리는 원문을 남기지 않으므로 같은 방식을 쓸 수 없다. 그래서 **남길 수 있는 것(횟수, 태그, 시간대)만으로 되돌아보는 경험**을 두 겹으로 만들었다.
  1. **눈에 보이는 누적**: 물든 알, 바퀴 수, 해금한 꾸미기. 기록 대신 쌓이는 것이다.
  2. **월 1회 비움 카드**: 통계 대신 "이번 달에 비워 낸 것"을 한 장으로 보여 준다.
- 두 장치 모두 날짜의 연속성을 보여 주지 않는다. 달력과 연속 기록을 쓰지 않아 스트릭처럼 느껴질 여지를 없앴다.

## 3. 최종 추천안

### 3.1 설계 원칙

1. **5.1 배출과 5.2 소각은 그대로 둔다.** 리텐션은 소각이 끝난 뒤부터 시작한다.
2. **안 써도 죄책감이 없다.** 진행도는 멈출 뿐 줄지 않는다. 연속 기록, 만료, 리셋, 미방문 불이익이 없다.
3. **원문은 남기지 않는다.** 남는 것은 3.2의 메타데이터뿐이다.
4. **보상은 꾸미기다.** 해금해도 염주의 기능은 같고, 모양과 느낌만 바뀐다.
5. **비운 것에 초점을 맞춘다.** 모든 문구는 부정 감정을 다시 불러내지 않고, "비워 냈다"는 행동을 인정한다.

### 3.2 남기는 데이터

| 남김 | 쓰는 곳 | 남기지 않음 |
| --- | --- | --- |
| 날짜 | 하루 적립 상한, 월간 비움 카드 | 원문 |
| 시간대 (새벽 / 아침 / 오후 / 저녁 / 밤 5구간) | 비움 카드, 알림 시간 추천 | 정확한 시각 (분 단위) |
| 감정 태그 (선택 입력) | 비움 카드, 알 물드는 색 | 글자 수 |
| 처리 방식 (분쇄기·화로·물 등) | 비움 카드 [추정: 필요 시] | 입력 중 로그, 수정 이력 |
| 마무리 의식 완료 / 건너뜀 여부 | 적립 판정, 의식 건너뛰기 비율 지표 | |
| 누적 적립 횟수, 해금 상태, 바퀴 수 | 염주 표시, 해금 | |

### 3.3 기본 염주 (메인)

- **18알 손목 염주**를 첫날부터 준다. 가입이나 적립 없이 바로 쓸 수 있다.
- **언제든 돌릴 수 있다.** 소각하지 않은 날에도, 적립 상한에 걸린 날에도 막히지 않는다.
- 홈 화면의 주인공은 기본 염주다. 108 진행률은 프로필(또는 도감) 안쪽에만 작게 표시한다.

### 3.4 적립 흐름: 소각 → 한 알 굴리기 → 물듦

```
[5.2 소각 연출 + 위로 문구] 
      ↓
기본 염주가 화면에 나타남 — "한 알 굴려 볼까요?"
      ↓                         ↘ [건너뛰기]
사용자가 알 하나를 넘김           소각은 정상 완료. 적립 없음. 불이익·경고 없음
(진동 + 굴릴 때 소리)
      ↓
굴린 알이 새 색으로 물듦 = 적립 1회
(감정 태그를 골랐다면 태그 색으로 물듦 [추정])
      ↓
해금 또는 한 바퀴 조건을 채웠으면 → 3.6 / 3.5 연출
```

- **마무리 의식 = 기본 염주 한 알 굴리기.** 약 5~10초 걸리는 한 번의 동작으로 끝이 분명하다. Pixel의 시간이 정해진 종료처럼 [김서영], 언제 끝나는지 예상할 수 있다.
- **하루 적립 상한은 3회다.** 넘은 뒤에는 굴려도 물들지 않고 "오늘은 충분히 비웠어요"만 보여 준다.

### 3.5 한 바퀴와 108 (서브 목표)

- 18알이 다 물들면 **"한 바퀴"** 완성 연출이 나온다(석가머니의 "한 바퀴" 단위 [정민규]).
- 다음 바퀴에서는 같은 알 위에 **색이 한 겹 더 깊게** 덧입혀진다(예: 연한 색 → 진한 색). 초기화하지 않는다.
- **18알 × 6바퀴 = 108회.** 6바퀴를 채우면 108 커스텀 염주가 완성된다. 23번째 해금과 같은 시점이다.
- 한 바퀴에 걸리는 시간은 하루 1회 적립 시 18일, 하루 3회 적립 시 6일이다.
- 108은 **서브 목표**다. 기한이 없고, 못 채워도 이미 가진 것은 모두 유지된다. 홈 화면에는 108 진행률을 두지 않는다.

### 3.6 꾸미기 해금 스케줄

**규칙**
- 해금 간격은 1, 2, 3, 4, 5, 6, 7회로 늘어나다가 28회 이후에는 **최대 5회**로 고정한다. 108회까지 총 23개다.
- ◆는 **선택형 뽑기**다. 2~3개 중 1개를 고르므로 중복이 없다. 해금 3번마다 한 번씩 온다.

## 4. PRD 5.3 이후 수정안

아래는 PRD v0.2에 넣을 수 있는 형태의 **수정 문안**이다. **PRD.md에는 직접 반영하지 않았다.** 팀 회의에서 확정한 뒤 반영한다. 5.1, 5.2, 6번 1~4단계는 변경하지 않는다.

### 5.3 기본 염주와 꾸미기 (리텐션 장치) — 전면 교체

- 첫 실행부터 18알 기본 염주를 제공한다. 기본 염주는 적립 여부와 관계없이 언제든 돌릴 수 있다.
- **적립**: 소각 후 마무리 의식(기본 염주 한 알 굴리기)을 마치면 굴린 알이 물들고 1회가 적립된다.
  - 의식은 건너뛸 수 있으며, 건너뛰면 적립되지 않는다(불이익 없음).
  - 하루 적립 상한은 3회다.
- **한 바퀴**: 18알이 모두 물들면 한 바퀴를 완성하고, 다음 바퀴는 색이 한 겹 깊어진다. 6바퀴(108회)를 채우면 108 커스텀 염주가 완성된다(서브 목표, 기한 없음).
- **꾸미기 해금**: 누적 1·3·6·10·15·21·28회에 해금하고, 이후 5회마다 해금한다(108회까지 23개).
  - 해금 3번 중 1번은 2~3개 중 고르는 선택형 뽑기다.
  - 보상은 구슬 색, 굴릴 때 소리, 재질·무늬, 매듭·술 장식이다. 외형만 바뀌고 기능은 같다.
- **단계별 제작**: MVP는 해금 1~7번(28회까지), 업데이트 1은 8~15번, 업데이트 2는 16~23번과 108 커스텀 염주다.
- **원칙**: 진행도는 줄지 않는다. 연속 기록, 만료, 리셋, 미방문 불이익이 없다.

### 5.4 월간 비움 카드 — 기존 "감정 리포트" 대체, v1에 포함

- 월 1회, 비운 횟수, 가장 많이 내려놓은 마음(태그), 주로 비운 시간대, 염주 바퀴 수를 카드 한 장으로 보여 준다.
- 날짜별 달력, 연속 기록, 추이 그래프는 넣지 않는다.
- 문구는 비운 행동에 초점을 맞추고("이번 달 12번 비워 냈어요"), 적게 온 달에도 탓하지 않는다("이번 달은 가볍게 지냈네요").
- 0회인 달에는 알림을 보내지 않는다.

### 5.5 데이터 보관 정책 — 신규

- 원문은 저장하지 않는다.
- 저장하는 것은 날짜, 시간대(5구간), 감정 태그, 처리 방식, 마무리 의식 완료 여부, 누적 적립 횟수, 해금 상태뿐이다.

### 6. 유저 플로우 — 5~7단계 교체

1~4. (변경 없음)
5. 기본 염주가 나타나고 **한 알 굴리기** → 굴린 알이 물들며 적립(건너뛰기 가능, 하루 3회 상한)
6. 해금 또는 한 바퀴 조건을 채웠으면 꾸미기 해금이나 한 바퀴 연출(뽑기 지점에서는 2~3개 중 선택)

### 8. 리텐션 전략 — 전면 교체

- **기본 염주 상시 사용**: 소각하지 않은 날에도 돌리며 마음을 가라앉힐 수 있다.
- **오늘의 한 줄**: 염주를 굴리면 하루 한 번 바뀌는 문구를 보여 준다(불교 문구와 비종교 문구 혼합).
- **저강도 알림**: 퇴근 시간대에 주 최대 3회, 사용자가 시간을 정한다. 2주 동안 오지 않으면 주 1회, 4주면 월 1회로 줄인다. 부재를 지적하는 문구는 쓰지 않는다.
