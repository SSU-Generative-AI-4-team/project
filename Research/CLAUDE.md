# Research 폴더 작업 규칙

이 폴더에서 이루어지는 모든 리서치 작업에 적용된다. 리서치 종류(시장·사용자·문헌)와 무관하게 아래 규칙은 항상 지킨다.

## 출처 원칙

- **모든 사실 주장에는 출처가 붙는다.** 형식: `[출처: 제목](URL) (접근: YYYY-MM-DD)`
- 출처를 확인하지 못한 내용은 삭제하지 말고 **`[미확인]`** 표시를 붙여 남긴다. 나중에 검증할 대상이 된다.
- **추측을 사실처럼 쓰지 않는다.** 추론한 내용은 `[추정]`으로 표시하고 근거를 함께 적는다.
- 2차 인용을 재인용하지 않는다. A가 B를 인용한 것을 봤다면 B 원문을 찾아 확인한다. 원문 확인이 불가능하면 `[2차 인용: A 경유]`로 명시한다.

## 교차검증

- 의사결정에 영향을 주는 수치·주장은 **독립된 출처 2곳 이상**에서 확인한다.
- 1곳에서만 확인됐다면 `[단일 출처]`로 표시한다. 표시 없이 넘어가지 않는다.
- 출처끼리 내용이 다르면 양쪽을 모두 적고 차이를 설명한다. 임의로 하나를 고르지 않는다.

## 파일 네이밍과 저장 위치

| 상태 | 위치 | 이름 형식 |
|---|---|---|
| 진행 중 조사 | `notes/` | `YYYY-MM-DD-주제슬러그.md` |
| 확정 산출물 | `outputs/` | `주제슬러그.md` |
| 출처 기록 | `sources/source-log.md` | 한 파일에 누적 |

- 슬러그는 소문자 영문/숫자와 하이픈만 사용한다. 예: `2026-09-22-competitor-pricing.md`
- 새 조사 노트는 반드시 `templates/research-note.md` 포맷을 따른다.
- 조사 중 참고한 출처는 그때그때 `sources/source-log.md`에 추가한다. 문서를 다 쓴 뒤 몰아서 정리하지 않는다.

## 문서 작성

- 본문은 한국어로 쓴다. 고유명사, 제품명, 기술 용어는 원문 표기를 유지한다. (예: Figma, A/B test, churn rate)
- 결론을 맨 앞에 둔다. 조사 과정은 그 뒤에 쓴다.
- 표로 정리할 수 있는 것은 표로 쓴다.

## 금기

- 날짜 없는 "최근", "요즘", "현재" — 반드시 구체적 시점을 쓴다
- 출처 없는 통계 수치
- "일반적으로", "대부분" 같은 근거 없는 일반화
- 조사하지 않은 내용을 채워 넣어 문서를 완성된 것처럼 보이게 만드는 것 — 빈 곳은 빈 채로 두고 `[조사 필요]`로 표시한다

## 사용 가능한 도구

| 상황 | 사용 |
|---|---|
| 시장·경쟁사 조사 | `Research:market` 스킬 |
| 사용자 인터뷰·설문 | `Research:user-interview` 스킬 |
| 기술·논문 조사 | `Research:literature` 스킬 |
| 자료 대량 수집 | `source-collector` 서브에이전트 |
