## A. 바로 반영 — 근거가 확인된 항목

### A1. 프라이버시 섹션 신설

**지금 PRD**: 136줄 전체에 프라이버시·보안 언급 0건

**근거**: 조사에서 가장 뚜렷하게 검증된 신호다.
- **감쓰** — *"글은 개발자도 못 본다"*를 전면 배치, 생체인증·암호 잠금 제공. **유료 앱인데도** 출시일 인기 48위, 이후 입소문만으로 주당 신규 ~600명
- **요단강** — 서버 전송 없이 로컬 저장을 내세움

**반영안**: PRD에 독립 섹션으로 추가한다.
- 원문 미보관을 기본값으로
- 미보관을 주장한다면 **서버와 분석 로그에도 원문을 보내지 않는다**
- 잠금(생체인증 또는 비밀번호)을 MVP에 포함

---

### A2. 염주 적립 기준을 "배출 횟수" → "세션 완료"로

**지금 PRD (5.3)**: 감정 배출 1회당 염주 1알

**근거**: 조사에서 **반대 근거가 나온 유일한 설계**다.
- *"분노 표현량과 파괴 횟수 비례 보상 — 해당 보상 기준의 도움 근거 없음"*
- *"보상의 목표 왜곡 — 부정적 감정을 더 쓰면 더 보상하는 구조는 배출량을 늘리도록 작동할 수 있다"*

정서 해소 서비스가 부정적 감정의 **생산**을 보상하는 구조가 된다.

**반영안**:
- 보상 단위를 **"한 번의 감정을 끝까지 마무리했는가"**로 변경
- **하루 적립 상한**을 둔다
- 작성 글자 수는 보상과 연동하지 않는다

---

### A3. 소멸 연출을 MVP에서 1종으로 축소

**지금 PRD (5.2)**: 분쇄기 / 화로 / 물에 흘려보내기 **3종**, "핵심 차별화" 표기

**근거**:
- 시각적 소멸은 이미 4개 서비스가 제공한다 — 감쓰(종이공·변기), 요단강(종잇배), Scream(즉시 소멸), Pixel Thoughts(별 축소). **연출 자체는 차별점이 아니다**
- 여러 테마는 *"한 연출의 추가 가치가 먼저"*로 LATER 분류됨

**반영안**:
- MVP는 **1종**만
- "(핵심 차별화)" 표기를 빼고 **검증 대상**으로 재정의 — *"일반 삭제 대비 종료감을 높이는지 확인이 필요한 항목"*

---

### A4. 108개 이전에 중간 보상 신설

**지금 PRD (5.3)**: 108개 단위로 팔찌/목걸이 완성

**근거**:
- **석가머니가 이미 "108번 = 액땜 한 바퀴"를 쓴다.** 차별 요소가 아니라 선점된 상징
- 1회 1알이면 108회까지 최소 108일. **Finch는 7회 완료**로 마이크로펫 하나를 준다 — 첫 보상까지 거리가 15배

**반영안**: 108은 최종 목표로 두고, 훨씬 짧은 주기의 중간 보상을 넣는다. 첫 보상 도달 횟수는 `[사용자 검증 필요]`

---

### A5. 차별화 표 교체 (7절)

**지금 PRD (7절)의 세 행이 경쟁사 실물과 맞지 않는다.**

| PRD가 적은 "기존 서비스" | 실제 |
|---|---|
| 감정을 "기록"하고 축적 | 직접 경쟁 12개 중 **9개가 배출·소멸형**. 기록형은 MOODA·Daylio·하루콩 3개뿐 |
| 스트릭 기반 리텐션 | Finch는 **스트릭 상실 페널티가 없다.** "스트릭=죄책감" 대비가 성립하지 않음 |
| 무미건조한 텍스트 UI | 감쓰는 종이공·변기 애니메이션 + "감정청소부" 캐릭터, 아무것도아니야는 진동 피드백 |

**반영안 — 대체 표**

| 비교 대상 | 그쪽이 가진 것 | 우리가 더하는 것 |
|---|---|---|
| 감쓰·요단강·Scream (배출형) | 강한 배출 경험 | **배출 이후의 누적** — 다시 열 이유 |
| 석가머니 (리추얼형) | 감정→리추얼→운 적립 루프 | **텍스트로 쓰고 없애는 단계** |
| MOODA·Finch (리워드형) | 검증된 수집 리텐션 | **적립물 자체가 의미를 갖는 구조** |
| 아무것도아니야 (종합 케어) | 배출 이후 여정 설계 | **가벼운 톤** — 임상 언어 없음 |

> "우리가 더하는 것"도 아직 가설이다. 검증 전까지 대외 문구로 쓰지 않는다.

---

### A6. 보관 경계 명문화 (5.2 ↔ 5.4)

**지금 PRD**: 5.2는 텍스트가 *"실제로 사라지는"* 경험을 약속하는데, 5.4는 감정 태그 통계를 제공한다

**근거**: **Pixel Thoughts는 시각적으로는 소멸시키면서 방침상 익명 저장한다고 명시**한다. 연출과 실제 저장이 다른 사례가 이미 있다

**반영안**: 모순이 아니라 경계를 정하면 해소된다.
- *원문은 저장하지 않는다. 감정 태그와 시각만 남는다*
- 이 문장을 **입력 화면에서 작성 전에** 보여준다

---

### A7. 위기 안내를 MVP 필수로 승격

**지금 PRD (10.4)**: "안전장치 필요 여부 검토"

**근거**: 경쟁사에 이미 있다. **아무것도아니야**는 PHQ-9 주간 자가진단, **마인드카페**는 전문가 상담·코칭 연계

**반영안**: MVP 필수 요건으로. 단 아무것도아니야는 *"톤이 무겁다"*는 게 약점이므로 임상 도구를 그대로 쓰지 말고 **최소한의 외부 기관 안내**로 시작

---

### A8. 출시명을 PRD 제목과 분리

**근거**: "감정쓰레기통"을 이름·부제에 쓰는 앱이 **5개** — 감쓰, 감정 쓰레기통(Studio Handot), 아무것도아니야(부제), 감정쓰레기통(thingapps), 감정쓰레기통: 요단강

**반영안**: 내부 프로젝트명(감정 쓰레기통)과 출시명을 분리한다

## B. 검증 후 반영 — A/B로 확인할 것

검증 순서: **일반 삭제 대비 연출 → 실제 미보관 가치 → 재사용 → 메시지와 보상**. 전부를 첫 2주에 넣지 않는다.

| # | 실험 | 확인할 것 | 근거 |
|---|---|---|---|
| B4 | 정적 삭제 vs 소멸 연출 1종 | 같은 입력·문구에서 **종료감**이 높아지는가. "새롭다"는 평가만으로는 부족 | 연출은 이미 4개가 제공 |
| B2 | 미보관 vs 선택적 보관 | 삭제·사생활·작성 부담 중 **무엇 때문에** 선택하는가 | 하루콩·Daylio는 기록의 가치를 전면에 내세움 |
| B3 | 무보상 vs 소박한 구슬 누적 | 다음 필요 상황에 **자발적으로** 다시 오는가. 배출 횟수만 늘지 않는지 함께 확인 | Finch 수집 구조 |
| B1 | 비종교 문구 vs 불교 문구 | 위로가 되는가, **설교로 느끼는가** | 불교 수용도 근거 부족. 불교마음은 리뷰 3건, 종교색이 젊은 층에 장벽 |

## 회의에서 정해야 할 것

1. **7절 차별화 표를 교체할 것인가** (A5) — 현재 표는 대외 설명에 쓰면 반박당한다
2. **염주 적립 기준을 바꿀 것인가** (A2) — 조사에서 반대 근거가 나온 유일한 설계
3. **염주를 유지할 것인가** — 김서영 조사는 불교 요소를 "근거 부족"으로 분류했고, 정민규님도 플로우 5번에 *"왁뿌볼이든 커스터마이징이든"* 대안 메모를 남겼다. **MOODA 스티커 선례는 비종교 수집물이 작동함을 보여준다** (사용자 요청으로 추가 → 크리에이터 스티커까지 확장). 반대로 불교마음은 연등·운세를 다 갖추고도 리뷰 3건
4. **첫 MVP를 전체 루프로 갈 것인가, 소멸 경험만 검증할 것인가** — [통합 분석 4절](./competitor-analysis.md)의 조재영 안 vs 김서영 안
5. **출시명 분리** (A8)
