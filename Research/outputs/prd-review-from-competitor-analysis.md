## 결론

1. **PRD 7절 "차별화 포인트" 표는 사실관계가 틀렸다.** 세 행 모두 경쟁사 실물과 맞지 않는다. 이 표를 근거로 차별성을 주장하면 위험하다.
2. **PRD가 "핵심 차별화"로 지목한 소각 연출(5.2)은 차별점이 아니다.** 최소 4개 서비스가 이미 시각적 소멸을 제공한다. 진짜 고유 영역은 **배출 → 의미부여 → 누적 리워드를 한 루프로 잇는 것**이고, 이것도 석가머니가 절반을 점유하고 있다.
3. **가장 시급한 수정은 5.3 염주 적립 규칙이다.** "배출 1회당 1알"은 조사에서 **반대 근거가 나온 유일한 설계**다. 부정적 감정을 더 쓸수록 보상이 커지는 구조로 작동할 수 있다.

## 1. 사실관계 수정이 필요한 곳

### PRD 7절 — 차별화 포인트 표

| PRD가 적은 "기존 서비스" | 실제 조사 결과 | 판정 |
|---|---|---|
| 감정을 "기록"하고 축적 | 직접 경쟁 12개 중 **9개가 배출·소멸형**이다. 감쓰(종이공·변기), 요단강(종잇배), Vent(음성), Scream(즉시 소멸), Pixel Thoughts(별 축소), 종이 폐기 등. 기록형은 MOODA·Daylio·하루콩 3개뿐 | **틀림** |
| 스트릭(연속 출석) 기반 리텐션 | Finch는 **스트릭 상실 페널티가 없고** 복귀를 유도하는 설계다. "스트릭 = 죄책감"이라는 대비가 성립하지 않는다 | **부정확** |
| 텍스트 기반 무미건조한 UI | 감쓰는 종이공 던지기·변기 물 내리기 애니메이션과 "감정청소부" 캐릭터를, 아무것도아니야는 진동 피드백을 제공한다 | **틀림** |

**`[제안]` 7절 대체안**

| 비교 대상 | 그쪽이 가진 것 | 우리가 더하는 것 |
|---|---|---|
| 감쓰·요단강·Scream (배출형) | 강한 배출 경험 | **배출 이후의 누적** — 다시 열 이유 |
| 석가머니 (리추얼형) | 감정→리추얼→운 적립 루프 | **텍스트로 쓰고 없애는 단계** — 감정의 외화(外化)와 소멸 |
| MOODA·Finch (리워드형) | 검증된 수집 리텐션 | **적립물 자체가 의미를 갖는 구조** (단순 꾸미기가 아님) |
| 아무것도아니야 (종합 케어) | 배출 이후 여정 설계 | **가벼운 톤** — 임상 언어 없음 |

> 이 표의 "우리가 더하는 것"도 아직 **가설**이다. 검증 전까지 대외 문구로 쓰지 않는다.

### PRD 5.2 — "핵심 차별화" 표기

소각 연출을 핵심 차별화로 두는 근거가 없다. 김서영 조사의 표현 그대로: *"텍스트를 입력하고 사라지게 만드는 서비스는 이미 존재한다. 따라서 소각 애니메이션 자체는 충분한 차별점이 아니다."*

**`[제안]`** 5.2의 "(핵심 차별화)" 표기를 빼고, 검증 대상으로 재정의한다 — *"일반 삭제 대비 종료감을 높이는지 확인이 필요한 항목"*.

## 2. 설계 위험 — 조사에서 반대 근거가 나온 항목

### 2.1 `5.3` 감정 배출 1회당 염주 1알 — **가장 시급**

| 항목 | 내용 |
|---|---|
| 충돌 근거 | 김서영 조사 DROP 항목: *"분노 표현량과 파괴 횟수 비례 보상 — 해당 보상 기준의 도움 근거 없음"* |
| 추가 위험 | 같은 조사의 위험 목록: *"보상의 목표 왜곡 — 부정적 감정을 더 쓰면 더 보상하는 구조는 배출량을 늘리도록 작동할 수 있다"* |
| 왜 문제인가 | 정서 해소 서비스가 **부정적 감정의 생산을 보상**하는 구조가 된다. PRD 11절 KPI의 "1인당 평균 주간 감정 배출 횟수"도 같은 방향으로 최적화를 유도한다 |
| **`[제안]`** | 보상 단위를 **배출 횟수 → 세션 완료**로 바꾼다. 즉 "얼마나 많이 썼는가"가 아니라 "한 번의 감정을 끝까지 마무리했는가"에 1알을 준다. 하루 적립 상한을 둔다 |

### 2.2 `5.3` 108개 완성 단위

| 항목 | 내용 |
|---|---|
| 충돌 근거 | **석가머니가 이미 "108번 = 액땜 한 바퀴"를 쓰고 있다.** 차별 요소가 아니라 선점된 상징이다 |
| 도달 문제 | 배출 1회 = 1알이면 108회까지 최소 108일. Finch는 **7회 완료**로 마이크로펫 하나를 준다. 첫 보상까지의 거리가 15배 차이 |
| **`[제안]`** | 108은 **최종 목표**로 두되, 그 전에 **짧은 주기의 중간 보상**을 넣는다. 첫 보상 도달 횟수는 `[사용자 검증 필요]` |

### 2.3 `6` 유저 플로우 — 염주 돌리기 / 목탁

| 항목 | 내용 |
|---|---|
| 지지되는 쪽 | 염주 굴리기처럼 **각성을 낮추는** 반복 행위는 Kjærvik & Bushman(2024) 154개 연구 메타분석이 지지하는 방향이다 |
| 지지되지 않는 쪽 | 같은 메타분석에서 **각성을 높이는 활동은 전체적으로 분노 감소 효과가 없었다.** 격한 파괴 연출(분쇄기 굉음, 강한 타격)을 "더 시원하다"는 이유로 키우는 방향은 근거가 없다 |
| **`[제안]`** | 소각 연출의 방향을 **격렬함이 아니라 잔잔함**으로 잡는다. PRD 9절의 "불꽃놀이" 같은 고각성 프리미엄 연출은 근거가 약하다 |

### 2.4 `5.2` + `5.4` 내부 모순 — 소멸과 리포트

5.2는 텍스트가 *"실제로 사라지는"* 경험을 약속하는데, 5.4는 감정 태그 통계를 제공한다. 김서영 조사는 이를 LATER로 분류하며 *"미보관과 긴장 관계"*라고 지적한다.

**`[제안]`** 모순이 아니라 **경계를 명시**하면 해소된다 — *원문은 저장하지 않고, 감정 태그와 시각만 남긴다.* 다만 이 경계를 **입력 화면에서 사용자에게 먼저 보여줘야** 한다. Pixel Thoughts는 시각적으로는 소멸시키면서 방침상 **익명 저장한다고 명시**하고 있어, 연출과 실제 저장이 다른 사례가 이미 있다.

### 2.5 `4` D7 리텐션 20% 목표

김서영 조사의 위험 항목: *"낮은 사용 빈도 — 필요할 때만 쓰는 도구는 유용해도 매일 방문하지 않을 수 있다. **낮은 일간 방문율만으로 실패를 판단하면 안 된다.**"*

**`[제안]`** D7을 **주요 지표에서 보조 지표로 내린다.** 주요 지표는 *"비슷한 감정 사건이 다시 생겼을 때 자발적으로 다시 왔는가"*(사건 기반 재사용)로 둔다.

## 3. PRD에 없는데 조사에서 검증된 것

### 3.1 프라이버시 — **가장 큰 누락**

PRD 136줄 전체에 프라이버시·보안 언급이 **0건**이다. 그런데 조사에서 가장 뚜렷하게 검증된 신호가 여기 있다.

- **감쓰**는 *"글은 개발자도 못 본다"*를 전면에 배치하고 생체인증·암호 잠금을 제공한다. 조재영 조사의 판단: *"신뢰가 진입장벽을 낮춘다는 증거"*
- **요단강**은 서버 전송 없이 로컬 저장을 내세운다
- 감쓰는 **유료 앱인데도** 출시일 인기 48위, 주당 신규 ~600명

**`[제안]`** 프라이버시를 PRD의 **독립 섹션으로 신설**한다. 원문 미보관을 주장한다면 **서버와 분석 로그에도 원문을 보내지 않아야** 한다(김서영 KEEP 항목).

### 3.2 네이밍 — 스토어 검색 경쟁

"감정쓰레기통"을 이름·부제에 쓰는 앱이 **5개** 확인됐다: 감쓰, 감정 쓰레기통(Studio Handot), 아무것도아니야(부제), 감정쓰레기통(thingapps), 감정쓰레기통: 요단강.

**`[제안]`** PRD 제목을 그대로 앱 이름으로 쓰면 검색 노출에서 불리하다. 내부 프로젝트명과 출시명을 분리한다.

### 3.3 `10.4` 정신건강 안전장치 — 선례 있음

PRD가 "검토 필요 여부"로만 적은 항목인데, 경쟁사에는 이미 구현돼 있다. **아무것도아니야**는 PHQ-9 주간 자가진단을, **마인드카페**는 전문가 상담·코칭 연계를 제공한다.

**`[제안]`** "검토 필요"에서 **MVP 필수 요건**으로 승격한다. 단 조재영 조사가 지적한 대로 아무것도아니야는 *"톤이 무겁다"*는 게 약점이므로, 임상 도구를 그대로 쓰지 말고 **최소한의 외부 기관 안내**로 시작한다.

### 3.4 콘텐츠 소모 — PRD 8절 우려가 실물로 확인됨

PRD 8절이 *"문구 다양성 확보 — 반복 시 이탈 우려"*로 적은 것은 **불교마음** 사례로 뒷받침된다. 불교마음은 연등·운세·명언으로 매일 열 이유를 만들었지만 리뷰가 **3건**뿐이다. 반대로 **MOODA**는 스티커를 **사용자 요청으로** 추가하고 크리에이터 스티커까지 확장해 지속 사용을 만들었다.

**`[제안]`** 콘텐츠 풀을 우리가 채우는 대신 **적립물의 시각적 변화**로 반복 동기를 만든다. 정민규님이 플로우 5번에 남긴 메모(*"왁뿌볼이든 커스터마이징이든 소각 후 부수적 이벤트"*)가 이 방향과 맞고, MOODA 선례가 이를 지지한다.

## 5. MVP 범위 조정안

김서영 조사의 KEEP/TEST/LATER/DROP을 PRD 기능에 매핑했다.

### KEEP — 첫 MVP에 넣는다

- 가입 없이 한 번 시작
- 짧은 자유 텍스트 입력 (5.1)
- **보관 범위를 입력 전에 안내** (신설)
- 소멸 연출 **1종** (5.2 축소)
- 짧은 마무리 문구 + 나가기
- 세션 완료 기준 적립 1알 (5.3 수정)
- 위기 상황 외부 기관 안내 (10.4 승격)

### TEST — 검증 순서대로

> **일반 삭제 대비 연출 → 실제 미보관 가치 → 재사용 → 메시지와 보상** 순서. 전부를 첫 2주에 넣지 않는다.

1. 정적 삭제 vs 소멸 연출 1종 — 종료감이 높아지는가
2. 미보관 vs 선택적 보관 — 무엇 때문에 선택하는가
3. 무보상 vs 소박한 구슬 누적 — 자발적 재사용이 늘어나는가 (배출 횟수만 늘지 않는지 함께 확인)
4. 비종교 문구 vs 불교 문구 — 위로되는가, 설교로 느끼는가

### LATER

감정 태그 통계·리포트(5.4) / 여러 소각 테마(5.2) / 108개 완성 보상(5.3) / 커스터마이징 스킨 / 계정·동기화 / 구독·프리미엄(9)

### DROP — 첫 MVP에서 제외

- 배출 횟수 비례 보상 (5.3)
- 퇴근시간 푸시 알림 (8) — 알림 기본 OFF로 시작
- 필수 불교 온보딩
- "감정이 완전히 사라진다"는 약속 문구

## 6. 회의에서 정해야 할 것

1. **7절 차별화 표를 교체할 것인가** — 현재 표는 대외 설명에 쓰면 반박당한다
2. **염주 적립 기준을 배출 횟수에서 세션 완료로 바꿀 것인가** — 조사에서 반대 근거가 나온 유일한 설계
3. **염주를 유지할 것인가** — 김서영 조사는 불교 요소를 "근거 부족"으로 분류했고, 정민규님도 플로우 5번에 대안 메모를 남겼다. MOODA 스티커 선례는 **비종교 수집물**이 작동함을 보여준다
4. **첫 MVP를 전체 루프로 갈 것인가, 소멸 경험만 검증할 것인가** — [통합 분석 4절](./competitor-analysis.md#4-팀-내-결론-대조)의 조재영 안 vs 김서영 안
5. **출시명을 PRD 제목과 분리할 것인가**
