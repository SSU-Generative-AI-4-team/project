## D1. 첫 MVP는 소멸 경험만 검증한다

배출 → 위로 문구 → 적립으로 이어지는 전체 루프 대신, **일반 삭제 대비 소멸 연출이 종료감을 높이는가**만 확인한다.

**근거**: 시각적 소멸은 이미 4개 서비스가 제공한다(감쓰·요단강·Scream·Pixel Thoughts). 연출 자체는 차별점이 아니므로, 연출을 키우기 전에 연출이 실제로 작동하는지부터 확인한다.

### MVP에 들어가는 것

| 기능 | 비고 |
|---|---|
| 가입 없이 한 번 시작 | |
| 짧은 자유 텍스트 입력 | 글자 수를 성취 기준으로 삼지 않음 |
| 보관 범위를 입력 **전에** 안내 | 미보관을 주장하면 서버·분석 로그에도 원문을 보내지 않는다 |
| 소멸 연출 **1종** | 분쇄기/화로/물 중 하나. 잔잔한 방향 |
| 짧은 마무리 문구 + 나가기 | 비종교 문구로 시작 |
| 위기 상황 외부 기관 안내 | |
| 참가자 전후 상태 측정 | 원문 대신 감정 강도와 종료감만 수집 |

### MVP에서 빠지는 것

적립물 전체(정원 포함) · 불교 문구 · 감정 태그 통계 · 푸시 알림 · 계정/동기화 · 수익화

## D2. 염주를 정원으로 대체한다

태운 감정이 **재**가 되고, 재가 **거름**이 되어 **식물**이 자란다.

### 왜 염주를 뺐나

| 이유 | 근거 |
|---|---|
| 108 상징이 선점됨 | 석가머니가 "108번 = 액땜 한 바퀴"를 이미 사용 |
| 종교색이 진입장벽 | 불교마음은 연등·운세를 갖추고도 리뷰 3건. 조사에서 젊은 층 장벽 지적 |
| 근거 부족 | 마음챙김 수용이 불교 명칭·염주 선호를 입증하지 않음 |
| **배출과 인과가 없음** | 글을 태웠는데 왜 구슬이 생기는지 설명되지 않는다. 언제든 다른 것으로 갈아끼울 수 있는 보상이었다 |

### 왜 정원인가

재 → 거름 → 식물은 **배출과 인과가 성립한다.** 버린 것이 다음 것의 재료가 된다는 서사가 소각 연출에서 자연스럽게 이어진다.

비종교 수집물이 작동한 선례도 있다 — **MOODA**는 스티커를 사용자 요청으로 추가해 크리에이터 스티커까지 확장했다.

### `[확인 필요]` Finch와의 차별화

정원은 **Finch와 가장 가까운 안이다.** 이 차이를 설계로 만들지 못하면 차별성이 없다.

| | Finch | 우리 |
|---|---|---|
| 관계 | 펫을 **돌본다** (의무) | 버린 것이 **거름이 된다** (부산물) |
| 미수행 시 | 펫이 기다린다 | 아무 일도 없다 |
| 리스크 | 조사에서 **"진행 압박" 부정 경험** 확인됨 | 압박 없음이 설계 목표 |

**`[제안]` 보완책**: 재(灰) 안의 강점이었던 **"읽을 수 없는 기록"**을 정원에 이식한다. 식물의 **종류와 색이 감정 분포에 따라 결정**되게 하면, 정원이 읽을 수 없는 감정 지도가 된다.

- 원문 미보관을 유지하면서 "내 것"이라는 애착이 생긴다
- PRD 3절 페인포인트 2번(*"과거 기록이 계속 쌓여 다시 보기 싫어지는 문제"*)을 정면으로 푼다 — 읽을 수 없으므로 부담 없이 쌓인다
- 원문이 없으므로 **안전하게 공유 가능**하다

## D3. 적립 기준은 세션 완료당

**배출 1회당 1알**(현행 PRD 5.3)에서 **세션 완료당 1회 + 일일 상한**으로 바꾼다.

**근거**: 조사에서 반대 근거가 나온 유일한 설계였다.
- *"분노 표현량과 파괴 횟수 비례 보상 — 해당 보상 기준의 도움 근거 없음"*
- *"부정적 감정을 더 쓰면 더 보상하는 구조는 배출량을 늘리도록 작동할 수 있다"*

### 따라오는 변경

- PRD 11절 KPI에서 **"1인당 평균 주간 감정 배출 횟수" 삭제** — 같은 왜곡을 지표 쪽에서 반복한다
- 작성 글자 수는 보상과 연동하지 않는다
- 주요 지표는 **사건 기반 재사용**(비슷한 감정 사건이 다시 생겼을 때 자발적으로 왔는가). D7 리텐션은 보조 지표

---

## D4. PRD 7절 차별화 표를 교체한다

현행 표는 세 행 모두 경쟁사 실물과 맞지 않는다. 대체 표는 [기획 반영 항목 A5](./prd-review-from-competitor-analysis.md)에 있다.

단 대체 표의 "우리가 더하는 것"도 **아직 가설이다.** 검증 전까지 대외 문구로 쓰지 않는다.

---

## D5. 출시명은 가제로 유지한다

"감정 쓰레기통"을 프로젝트 가제로 계속 쓴다.

**`[보류] 출시 전 재검토 필요.`** 같은 이름을 쓰는 앱이 5개 확인됐다 — 감쓰, 감정 쓰레기통(Studio Handot), 아무것도아니야(부제), 감정쓰레기통(thingapps), 감정쓰레기통: 요단강. 스토어 등록 시점에는 검색 노출에서 불리하다.

참고: D2로 컨셉이 정원 쪽으로 이동했으므로, 네이밍 재검토 시 **소각·폐기 계열보다 정원·성장 계열**이 제품과 더 맞을 수 있다.
