# 🔥 불교 테마 감정 소각 서비스 아이디어 정리

## 1. 서비스 흐름 (3단계)

```
① 나를 돌보기   접속 → 오늘의 법구 → 감정 소각 → AI 스님 한마디
② 모으는 재미   향·연꽃 획득 → 인연 뽑기 / 마음 연못 → 띠별 수호불
③ 세상과 연결   연등 하늘 → 월간 리포트 공유 → 기부·사찰 연계
```

## 2. 확정 기능

| 기능 | 내용 | AI 활용 |
|---|---|---|
| **오늘의 법구** | 앱에 접속하면 오늘의 부처님 말씀 한 줄이 바로 떠요. 마음에 드는 구절은 경전첩에 저장해요 | 어려운 구절에 쉬운 해설을 붙여요 |
| **인연 뽑기** | 향을 모아 동자승·나한·보살 카드를 뽑아요 (일반 70% / 희귀 25% / 전설 5%, 30회 안에 전설 1회 보장) | 카드 일러스트를 이미지 AI로 만들어요 |
| **띠별 수호불** | 가입할 때 생년으로 수호불이 정해지고, 마음 연못이 만개하면 수호불이 등장해요 | 수호불 일러스트를 이미지 AI로 만들어요 |
| **마음 연못** | 연꽃 씨앗을 심어 키워요 (씨앗 → 싹 → 잎 → 봉오리 → 개화). 108송이가 피면 만개해요. 방치해도 시들지 않고 성장만 멈춰요 | 없음 |
| **함께하는 기능** | 연등 하늘(익명 소원 + 🙏 합장 반응만 허용), 목탁과 1분 호흡, 월간 번뇌 리포트 | 연등 소원 필터링, 월간 감정 패턴 분석 |

### 띠별 수호불 대응표 (초안, 검증 필요)

| 띠 | 수호불 |
|---|---|
| 쥐 | 천수관음 |
| 소 · 호랑이 | 허공장보살 |
| 토끼 | 문수보살 |
| 용 · 뱀 | 보현보살 |
| 말 | 대세지보살 |
| 양 · 원숭이 | 대일여래 |
| 닭 | 부동명왕 |
| 개 · 돼지 | 아미타불 |

## 3. 추천 추가 기능 (검토 중)

- **AI 스님 한마디** ⭐: 소각한 글을 AI가 읽고 사용자 상황에 맞춘 짧은 위로를 건네요
- **마음 온도 체크** ⭐: 소각 전후에 기분 점수를 매겨서 효과를 수치로 보여줘요
- **AI 위기 감지** ⭐: 위험 신호가 보이면 자살예방 상담전화 109를 안내해요
- **공덕 기부**: 모은 토큰을 실제 연등 기부나 마음건강 단체 후원으로 바꿔요
- **사찰 스탬프 투어**: 실제 사찰에 방문하면 한정판 카드를 줘요
- **대학생 시즌 모드**: 시험기간 합격 기원 연등, 취업 시즌 불합격 소각
- **불교 절기 이벤트**: 부처님오신날, 동지, 백중 한정 이벤트
- **미래의 나에게 편지**: 소각 후 1년 뒤에 도착하는 편지

## 4. 재화 설계 (초안)

| 재화 | 쓰는 곳 | 얻는 방법 |
|---|---|---|
| **향** 🪔 | 인연 뽑기 (1회 50개) | 소각 1회당 10~15개. 3~4일에 한 번 뽑는 속도예요 |
| **연꽃 씨앗** 🌱 | 마음 연못 | 소각 1회당 1개 |

- 소각 보상은 **하루 3회까지**만 줘요. 보상을 받으려고 감정을 억지로 만들어 쓰는 걸 막기 위해서예요.

## 5. 수익 모델

- **부분 유료화**: AI 월간 리포트, 연등·연못 꾸미기 아이템
- **제휴 수수료**: 템플스테이, 사찰 체험 예약 연결
- **B2B**: 기업 직원 복지, 대학 상담센터용 멘탈케어 도구
- **굿즈**: 인기 캐릭터(수호불, 동자승)로 만든 염주와 키링

## 6. 주의할 점

- **종교적 민감성**: "부처님 가챠" 대신 **"인연 뽑기"**라는 이름을 쓰고, 동자승과 나한 캐릭터를 중심에 둬요
- **확률형 아이템**: 유료 가챠를 넣으면 확률을 공개해요. 처음에는 무료 재화로만 뽑게 해요
- **AI 상담 한계**: AI 스님이 전문 상담을 대체하지 않는다는 안내를 넣어요
