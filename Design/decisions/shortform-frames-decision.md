# 숏폼 광고 프레임 시안 설계 근거

- 작성자: Claude Code로 작성 (작성자 이름 확인 필요)
- 날짜: 2026-11-17
- 관련 파일: `frontend/shortform_frames.html`

## 배경

광고로 돌릴 숏폼 영상(9:16, 15~20초)을 만들기 전에 장면 순서와 첫 3초 훅을 프레임으로 먼저 맞춘다. 12주차 강의자료(훅 모양 다섯, 쇼츠 대본 = 첫 2초 훅 + 장면 4개)를 따랐다.

## 검토한 대안

| 소재 | 훅 | 비고 |
| --- | --- | --- |
| 보내지 않은 메시지 · POV · 궁궐 앞 해치 | 질문 · 장면 | 말로 끄는 훅이라 자막이 길어짐. 2차 후보 |
| 실제 화면 데모 · 먹 갈기 | 장면 · 소리 | 앱 화면 녹화가 필요하거나 재방문용. 다음에 |
| 숫자 훅 | 숫자 | 근거 숫자(테스터 데이터)가 없어 제외 |

## 최종 결정과 근거

훅 방식이 서로 다른 3개로 1차 시안을 만든다. 같은 끝 장면을 두고 첫 3초만 비교하기 위해서다.

- A 해치 먹방 ASMR: 소리 + 패턴 깨기
- B 메모장 vs 해칫: 반전(비교) + 장면
- C 해치의 한마디: 캐릭터 대사 + 되감기 · 루프

`brand_1013.md`는 자극적인 말을 쓰지 않으므로 훅은 말 대신 소리 · 움직임 · 의외의 장면으로 만든다. 자막은 금지어(소각 · 힐링 · 치유 등)를 피하고 "원문은 남지 않아요"로 쓴다. 사람 얼굴 · 지어낸 숫자 · 후기는 넣지 않는다. 자막은 릴스 · 쇼츠 UI가 가리지 않는 영역 안에 둔다.
